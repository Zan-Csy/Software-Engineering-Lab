## 四、状态模型摘要

### B1 恒温水箱

- 复合状态“恒温运行”包含：温度/水量检测、加热、停止加热、无水保护；
- 温度低于 20℃ 且有水：闭合继电器加热；
- 温度低于 20℃ 且无水：进入无水保护，不打开电源；
- 温度达到 100℃：断开继电器；20℃～100℃ 保持断开；
- 23:00 进入休眠，07:00 恢复检测；
- 水箱故障进入维修，维修完成复位；
- 虚线迁移是对“温度回升、水位恢复、维修复位”的合理补全，报告中单独说明。

### B2 SafeHome 控制面板

- 状态：空闲/待机、读取键入字符、密码校验、系统功能选择、锁定；
- 密码长度 4 位，输满 4 位后校验；
- 连续 3 次密码错误进入锁定，锁定 120 秒；
- 锁定期间按键抛出 `PanelLockedError`，120 秒后可重新输入；
- 密码正确进入系统功能选择，退出后回到空闲/待机。

### B3 字符串提取

- 状态：普通文本、字符串读取、转义读取、结束、异常结束；
- 字符串内普通字符写入缓冲区；反斜杠进入转义读取，下一个字符原样写入；
- 双引号结束当前字符串并输出；
- EOF 时仍在字符串内或转义读取中，抛出带行号、列号的 `UnterminatedStringError`；
- 按题目“转义下一个字符”的文字要求，`\n` 输出 `n`，不解释为换行符；`\"` 输出 `"`，`\\` 输出 `\`。
